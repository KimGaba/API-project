Start with a small, predictable contract

1. Point at the local API

Use http://192.168.86.23:3011 as the base URL for this MVP.

2. Send the demo key

Authenticated routes require x-api-key: demo_live_123.

3. Start with metadata or search

List enabled countries first, then query seeded company rows by name, registration number, and country.

List supported countries

          

            

              

                GET
                /v1/meta/countries
                Requires x-api-key
              

              
Returns the current country catalogue for the MVP, including what is enabled now and what is only listed for roadmap context.

              

                
                  

                    Field
                    Type
                    Notes
                  

                
                
                  
codestring2-letter country code

                  
namestringDisplay name

                  
enabledbooleanWhether the MVP currently serves it

                  
sourceStatusstringplanned, pilot, or active

                
              

            

            

              
Example response

              
{
  "data": [
    { "code": "NO", "name": "Norway", "enabled": true, "sourceStatus": "pilot" },
    { "code": "GB", "name": "United Kingdom", "enabled": true, "sourceStatus": "pilot" },
    { "code": "DK", "name": "Denmark", "enabled": false, "sourceStatus": "planned" },
    { "code": "FI", "name": "Finland", "enabled": false, "sourceStatus": "planned" }
  ],
  "meta": {
    "total": 4
  }
}

            

          

        


        

          
Search companies

          

            

              

                GET
                /v1/companies/search
                Requires x-api-key
              

              
Search seeded demo rows by company name or registration number, with optional country filtering.

              

                
                  

                    Query param
                    Type
                    Rules
                  

                
                
                  
qstringOptional. 1–120 chars after trim.

                  
countrystringOptional. Must be a 2-letter code like NO or GB.

                  
limitnumberOptional. Integer from 1 to 50. Default 10.

                
              

              

                Search currently reads from seeded demo data. Example hits include Nordic Data Example AS and Example Analytics Ltd.

{

      "status": "active",
      "source": "seed"
    },
    {
      "id": "6a8c19dd-aaaa-bbbb-cccc-555555555555",

          Error format
          
Errors stay plain JSON and easy to debug

          

            

              401 unauthorized
              
Returned when the request is missing the API key header or includes an invalid key.

              

                
{
  "error": "UNAUTHORIZED",
  "message": "Missing or invalid API key. Send x-api-key header."
}

              

            

            

              400 bad request
              
Returned when search query parameters do not satisfy validation rules.

              

                
{
  "error": "BAD_REQUEST",
  "message": "Invalid search query",
  "details": {
    "formErrors": [],
    "fieldErrors": {
      "limit": ["Number must be less than or equal to 50"]
    }
  }
}
