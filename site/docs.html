Start with a small, predictable contract.

Use http://192.168.86.23:3011 as the base URL, send x-api-key: demo_live_123 for authenticated routes, and start with metadata or search.

Open demoSee supported countries
1. Point at the local API

Base URL: http://192.168.86.23:3011

2. Send the demo key

x-api-key: demo_live_123

3. Start small

List countries first, then query seeded companies.

4. Use the same routes in demo

The browser playground uses the exact same paths.

cURL
curl -s "http://192.168.86.23:3011/v1/meta/countries" \
  -H "x-api-key: demo_live_123"
JavaScript fetch
const res = await fetch("http://192.168.86.23:3011/v1/companies/search?q=Example&country=GB", {
  headers: { "x-api-key": "demo_live_123" }
});

const json = await res.json();
console.log(json);

Unauthenticated service heartbeat for smoke tests and quick local verification.

Response
status, service, timestamp
Use case
Monitoring and browser sanity tests

{

  "service": "company-data-api",

List supported countries

GET/v1/meta/countriesRequires x-api-key

Returns the current country catalogue for the MVP.

FieldTypeNotes
codestring2-letter country code
namestringDisplay name
enabledbooleanWhether the MVP currently serves it
sourceStatusstringplanned, pilot, or active
Example response
{
  "data": [
    { "code": "NO", "name": "Norway", "enabled": true, "sourceStatus": "pilot" },
    { "code": "GB", "name": "United Kingdom", "enabled": true, "sourceStatus": "pilot" }
  ],
  "meta": { "total": 4 }
}

Search companies

GET/v1/companies/searchRequires x-api-key

Search seeded demo rows by company name or registration number, with optional country filtering.

Query paramTypeRules
qstringOptional. 1–120 chars after trim.
countrystringOptional. Must be a 2-letter code like NO or GB.
limitnumberOptional. Integer from 1 to 50. Default 10.
Search currently reads from seeded demo data. Example hits include Nordic Data Example AS and Example Analytics Ltd.
Example response
{
  "data": [
    {
      "countryCode": "GB",
      "registrationNumber": "12345678",
      "name": "Example Analytics Ltd",
      "status": "active"
    }
  ],
  "meta": {
    "query": "Example",
    "country": null,
    "limit": 10,
    "total": 2
  }
}
Errors
401 unauthorized

Returned when the request is missing the API key header or includes an invalid key.

{
  "error": "UNAUTHORIZED",
  "message": "Missing or invalid API key. Send x-api-key header."
}
400 bad request

Returned when search query parameters do not satisfy validation rules.

{
  "error": "BAD_REQUEST",
  "message": "Invalid search query"
}
