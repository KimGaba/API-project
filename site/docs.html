A small contract. Quick to integrate.

Base URL, one auth header, three endpoints. Most integrations are up and running in under an hour.

Try it live See supported countries
1. Set the base URL

Base URL: http://192.168.1.10:3011

2. Add your API key

Header: x-api-key: demo_live_123

3. Start with countries

List available countries, then query companies.

4. Run it in the demo

The browser playground uses the exact same routes.

cURL
curl "http://192.168.1.10:3011/v1/companies/search
  ?q=Example&country=NO&limit=5" \
  -H "x-api-key: demo_live_123"
JavaScript
const res = await fetch(
  "http://192.168.1.10:3011/v1/companies/search
   ?q=Example&country=GB",
  { headers: { "x-api-key": "demo_live_123" } }
);
const data = await res.json();
Endpoints

Health check

GET /health No auth required

Unauthenticated heartbeat for monitoring and smoke tests.

Response
status, service, timestamp
Use case
Uptime monitoring, deployment checks
Response
{
  "status": "ok",
  "service": "company-data-api",
  "timestamp": "2026-05-18T12:00:00.000Z"
}

List supported countries

GET /v1/meta/countries Requires x-api-key

Returns the current country catalogue — which markets are live and their source status.

FieldTypeNotes
codestringISO 3166-1 alpha-2 country code
namestringCountry display name
enabledbooleanWhether the country is queryable today
sourceStatusstringplanned, pilot, or active
Response
{
  "data": [
    { "code": "NO", "name": "Norway",
      "enabled": true, "sourceStatus": "pilot" },
    { "code": "GB", "name": "United Kingdom",
      "enabled": true, "sourceStatus": "pilot" }
  ],
  "meta": { "total": 4 }
}

Search companies

GET /v1/companies/search Requires x-api-key

Search companies by name or registration number, with optional country filtering.

ParameterTypeRules
qstringOptional. 1–120 chars.
countrystringOptional. 2-letter code: NO, GB.
limitnumberOptional. 1–50, default 10.
Response
{
  "data": [
    {
      "countryCode": "NO",
      "registrationNumber": "987654321",
      "name": "Nordic Data Example AS",
      "status": "active"
    }
  ],
  "meta": {
    "query": "Example",
    "country": "NO",
    "limit": 10,
    "total": 1
  }
}
Errors
401 Unauthorized

Missing or invalid x-api-key header on authenticated routes.

{
  "error": "UNAUTHORIZED",
  "message": "Missing or invalid API key."
}
400 Bad Request

Query parameters fail validation — e.g. limit out of range or invalid country code.

{
  "error": "BAD_REQUEST",
  "message": "Invalid search query"
}
