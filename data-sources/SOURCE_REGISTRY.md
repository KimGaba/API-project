# Source Registry Draft

## Priority sources to evaluate

### Denmark
- CVR / Virk-related public data
- VAT validation cross-checks where lawful
- potential open datasets around company status and address data

### United Kingdom
- Companies House API / bulk data products
- officer / filing / status data

### Norway
- Brønnøysundregistrene open/company data endpoints

### Finland
- PRH / BIS related datasets and interfaces

### France
- INSEE / SIRENE datasets
- data.gouv.fr mirror/open datasets

## EU-wide supporting sources
- VIES VAT validation
- GLEIF / LEI data
- EU open data portals
- procurement / tenders for enrichment

## Required legal checklist per source
- Is commercial reuse allowed?
- Is redistribution allowed?
- Is API resale allowed?
- Are there attribution requirements?
- Is bulk download permitted?
- Are there anti-scraping restrictions?
